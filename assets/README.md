# Assets

Non-code media for public repo/docs/store listings.

## Folders

- `screenshots/` - browser store screenshots and demo captures
- `store/` - Chrome Web Store / AMO listing media (feature graphics, promo images)
- `promo/` - social preview and marketing banners
- `docs/` - images/GIFs embedded in README or documentation
- `branding/` - logos, color references, brand assets
- `icons/` - source icon files (e.g. SVG/PSD), not runtime extension icons
- `videos/` - short demo videos

Notes:
- Runtime extension icons remain in the root `icons/` folder used by `manifest.json`.
- Keep large export/source files only if needed for maintenance.
